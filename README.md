# gh-switcher

Расширение для Chrome (а также Edge и Brave) для быстрого перехода из репозитория на GitHub в:

- [GitIngest](https://gitingest.com) — текстовая выгрузка репозитория для LLM;
- [GitDiagram](https://gitdiagram.com) — диаграмма архитектуры репозитория.

На странице репозитория появляются две кнопки в правом нижнем углу. Иконка расширения в панели цветная на github.com и серая на остальных сайтах.

## Установка

1. Откройте страницу [Releases](https://github.com/Wwwoper/gh-switcher/releases) и скачайте `gh-switcher.zip` из последнего релиза.
2. Распакуйте архив в постоянную папку. Её нельзя удалять, пока расширение установлено.
3. Откройте `chrome://extensions` (в Edge: `edge://extensions`).
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку.
6. Закрепите расширение в панели браузера (значок пазла, затем булавка).

## Обновление

Скачайте новый `gh-switcher.zip`, замените файлы в папке и нажмите кнопку обновления у расширения на `chrome://extensions`.

## Установка из исходников

```bash
git clone https://github.com/Wwwoper/gh-switcher.git
```

Затем загрузите папку `extension/` как распакованное расширение.

## Разрешения

| Разрешение | Зачем |
| --- | --- |
| `host_permissions: https://github.com/*` | Показывать кнопки на GitHub и определять, что открыт github.com, для смены иконки |

Расширение не собирает данные и никуда их не отправляет. Ссылки формируются локально из адреса страницы.

## Структура

```
extension/
  manifest.json    # манифест (Manifest V3)
  content.js       # вставляет кнопки на страницу репозитория
  content.css      # стили кнопок
  background.js    # переключает цветную и серую иконку
  icons/           # иконки (цветные и серые)
```

## Как выпустить релиз

1. Обновите `version` в `extension/manifest.json`.
2. Создайте и отправьте тег:

```bash
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions соберёт `gh-switcher.zip` и прикрепит его к релизу. Версия в теге должна совпадать с версией в манифесте.
